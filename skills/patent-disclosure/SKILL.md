# 专利挖掘与交底书助手（CMS / ODMS）

范围：只做代理人之前的工作——**挖掘 → 创新点 → 交底书**。不写权利要求/说明书。

## 两阶段流程（必须按序，阶段间有人工闸口）

```
素材 → [阶段1] 挖掘表行(追加到飞书表格) → 知识产权部门确认(闸口) → [阶段2] 技术交底书(按模板) → 交代理人
```

- 未获用户明确说明"IP 已确认某序号"，**不得进入阶段2**。
- 阶段1只在表格**末尾追加行**，不改动、不删除已有行；写入前向用户展示拟写内容并确认。

## 阶段1：专利挖掘（输出：表格新增行）

### 1. 挖掘来源与线索
需求/方案评审、架构与算法设计、问题单与 8D、测试数据、竞品拆解。优先抓：
- 攻克了难题的地方（原做法失效/有副作用）
- 与行业常规做法不同的地方
- 效果可量化（延时、误判率、成本、BOM、功耗）
- **可被侵权取证**的地方（外部可观测：通信报文、接口、外观结构、可反向工程的行为）

### 2. 创新点识别（问题-手段-效果）
对每个候选点追问：为什么不用常规方案？是否有替代实现？能否上位概括？步骤间的控制逻辑是什么（条件判断→进入下一步）？
过滤：纯算法且外部不可见 → 维权难，须设法落到可观测的系统/接口/信号特征，否则降级。

### 3. 表格列规范（共 21 列，写前须重读表头核对）

| 列 | 字段 | 填写要求 |
|---|---|---|
| A | 序号 | 接续最后一行 +1 |
| B | 方案概念 | 一句话，格式"一种XXX系统/方法" |
| C | 优先级 | P0/P1/P2（业务价值+可维权性+竞品覆盖） |
| D | 技术问题 | 现有方案做法 + 其缺陷（具体到器件/信号/场景） |
| E | 技术手段 | "一种XXX系统，包括…：①…②…③…"分步编号，含使能条件、阈值、回退/DTC 等具体特征 |
| F | 技术效果 | 尽量量化，对应 D 的缺陷逐条回应 |
| G | 专利可行性评估 | 如"高，申请发明专利"；含公开线索摘要、风险与建议（引 `公开专利检索` 页结论） |
| H | 负责人 | 提出人/挖掘人 |
| I | 一阶段完成时间 | 日期 |
| J | 新创性评估—IP | **留空，由知识产权部门填** |
| K | 交底书完善方向 | **留空，由 IP 填**（可在对话中预给建议，不写入） |
| L–N | 对比文件 | 留空或填检索到的链接（IP/检索环节填） |
| O | 专利编写负责人 | 留空或按用户指定 |
| P–U | 其他 | 留空 |

> 已有样例见 [references/mining-table-samples.md](references/mining-table-samples.md)，写作粒度和语气对齐样例。

### 4. 同步公开检索页（可选）

### 5. 阶段1自检
- [ ] E 栏有可落地的具体特征（阈值/条件/回退），不只讲"做什么"
- [ ] D 栏缺陷与 F 栏效果一一对应
- [ ] 标注了可维权性判断（外部可观测点）
- [ ] 与已有序号不重复（先读全表比对 B 列）
- [ ] 无需保密的无关内部信息（项目代号、客户名、报价）

## 阶段2：技术交底书（输出：飞书 docx）

前置：用户确认哪个序号已通过 IP 评审，并提供/同意 IP 在 J、K 列的意见。

### 步骤
1. 读取该行 D/E/F 及 J/K（IP 意见与完善方向）；缺失信息向用户追问，不得编造参数。
2. 按 [references/disclosure-template.md](references/disclosure-template.md) 的 7 个栏目逐项撰写。
3. 逐条落实 K 列"完善方向"（如上位化步骤、补控制逻辑图、补实际场景案例）。
4. 附图：给出流程图/框图的**文字版结构 + 可导入 Mermaid/说明**，让用户或 `lark-whiteboard` 生成图；图中标号与正文一致。
5. 用 `lark-doc` 创建新文档，标题为"远峰科技专利提案书-<发明创造名称>"，展示给用户确认后再写入。

### 阶段2写作要点
- **背景技术**：行业做法 + 别人怎么做；不夸大自家。
- **技术问题**：他们的缺点，及解决某问题时是否带来新问题。
- **有益效果**：客观、可量化，对应缺陷。
- **发明点**：编号列出 3–5 个，每点是"可独立保护的特征"，并在实施方式中展开；尽量给上位表述（如"摄像头"→"图像采集装置"）并保留下位。
- **最优实施方式**（≥500 字）：硬件（模块架构/电路/原理）、结构（形状/连接/位置）、系统（控制逻辑，含使能条件→判断→动作→回退）；给出具体参数与取值范围。
- **替代实施例**：可替换技术特征、替换后对效果的影响、最基本方案。
- 术语全文一致；每句都能回答"怎么做"。

### 阶段2自检
- [ ] 7 栏目齐全，最优实施方式 ≥500 字
- [ ] 发明点均在实施方式中有展开
- [ ] K 列完善方向全部落实或说明未落实原因
- [ ] 有控制逻辑图/框图，编号与正文一致
- [ ] 有替代实施例与最基本方案
- [ ] 提案人姓名电话已填

## 注意
- 代理人负责权利要求与说明书；本技能产出不用"权利要求"措辞。
- 查新结论仅为线索，最终以智慧芽/IP 部门为准。
- 写飞书表格/文档前一律先预览并获用户确认。
