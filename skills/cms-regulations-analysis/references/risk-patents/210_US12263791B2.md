# 序号210｜US12263791B2｜具有微透镜阵列摄像头的车辆驾驶员监控系统｜MAGNA ELECTRONICS INC.｜申请日2021/6/8｜公开2025/4/1

【状态】已授权，31项权利要求，独立权利要求1/14/17/24。连续案，最早优先权2012-12-07，申请日2021-06-08，授权日2025-04-01（表内申请日以此为准）。Magna Electronics。
【权利要求1要素（须全部满足）】①舱内摄像头视场含驾驶员头部区域；②成像阵列为二维阵列，≥100万像素；③成像器前方设**二维微透镜阵列(lens array)**，至少2行×2列透镜元件；④每个透镜元件各自覆盖成像器上一块子阵列(sub-array)并成像；⑤成像器对近红外敏感，舱内NIR照明源照亮头部；⑥图像处理器根据各子阵列图像，确定驾驶员头部及其朝向（facing direction）。
【独立权利要求差异】14：不要求“至少2×2”，但增加“通过比较不同子阵列的图像确定到头部的距离”；17：获取头部深度信息（距离+摄像头相对头部视角），并确定面朝方向和**眼睛注视方向**；24：子阵列≥5000像素，获取深度信息，并确定头部及面朝方向。
【从属要点】深度图及用于驾驶辅助；头部/眼睛跟踪；立体视觉；透镜元件焦距相近；子阵列≥50万/≥5000像素；NIR LED或NIR激光。
【技术本质】本专利核心是“光场/阵列相机(微透镜阵列)+子阵列图像比较获取深度”，属特殊光学传感器，不是普通单镜头DMS摄像头。
【与我方覆盖】我方ODMS若使用常规单镜头+CMOS(RGB-IR/NIR)摄像头，没有二维透镜阵列覆盖子阵列这一结构，缺要素③④，不覆盖。仅当采用光场相机、微透镜阵列多视角相机，或多孔径阵列相机做深度估计时才需关注。
【维权难度】中：结构特征（拆解可见微透镜阵列、每透镜对应一个子阵列）客观易证；但覆盖范围仅限阵列相机，且2012年优先权的光场相机相关在先技术较多，无效风险不低。
【规避建议】使用常规单镜头摄像头；深度信息用ToF/结构光/雷达或双目分立相机（两个独立镜头+各自成像器，不是同一成像器上的透镜阵列）；注意不要在一个成像器前加透镜阵列做子阵列成像。
【对我方风险】低。以上为初步分析，非法律意见，建议美国律师核对。
