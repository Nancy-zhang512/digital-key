# 序号193｜US12084063B2｜车辆座舱监控系统｜MAGNA ELECTRONICS INC.｜申请日2023/2/20｜公开2024/9/10

【状态】已授权，82项权利要求，独立权利要求1/34/57/76。连续案(最早可追溯至2016-10-20优先权，2017-10-19、2021-09-13申请)，申请日2023-02-20。Magna Electronics。
【权利要求1要素（须全部满足）】①舱内摄像头拍摄驾驶员**且**同时拍摄至少一个其他座位；②车内处理器处理图像；③检测车内有乘员；④监控驾驶员；⑤**车辆控制被调整**，依据“驾驶员监控结果+检测到的乘员”两者。
【独立权利要求差异】34：车辆控制按“驾驶员被判定分心”调整（不再要求依据乘员调整，但仍要求检测乘员）；57：检测到的乘员为儿童或婴儿，且据乘员存在调整车辆控制；76：驾驶员监控包含跟踪眼睛，处理器为ECU并集成在内后视镜总成。
【从属要点】学习驾驶风格并据此调整控制；对乘员分类（婴儿/儿童/老人）；分类依据体型/年龄/进食/饮水等；跟踪头部位置/方向、眼睛、手势；ECU位于内后视镜；根据乘员进食/饮水调整控制；驾驶员异常驾驶/违规操作。
【覆盖要点】权利要求较宽：只要“一个舱内摄像头同时看到驾驶位+另一座位 + 检测乘员 + 监控驾驶员 + 据此调整车辆控制”。“车辆控制被调整”含义较宽（说明书/从属涉及ADAS灵敏度、报警、驾驶风格等），需律师判定。
【与我方覆盖】ODMS若为单摄像头同时覆盖驾驶员与副驾/后排（常见广角DMS/OMS一体方案）并做乘员检测，且结果影响车辆控制（如ADAS/报警/安全气囊策略），则覆盖风险中~高。若只拍驾驶员（窄视场），或乘员检测不与车辆控制联动（仅输出信号给上层，由上层决定），则可能缺要素；但“调整车辆控制”边界待判断。
【维权难度】中：摄像头视场覆盖可直接拆解/测量；“车辆控制被调整”需整车联动测试，且可能由OEM而非我方实现，维权涉及Tier1与OEM分工。
【规避建议】①单摄像头只覆盖驾驶位(窄FOV)，副驾/后排用独立传感器；②乘员检测结果只输出给OEM，不在本系统内驱动车辆控制，并在接口文档明确；③不做对婴儿/儿童检测联动控制；④避免“驾驶员监控+乘员信息联合调整控制”的逻辑。
【对我方风险】中，若产品是DMS/OMS一体方案则风险较高，应逐条对照独立权利要求1/34/57/76。以上为初步分析，非法律意见，建议美国律师核对（含审查历史及同族）。
