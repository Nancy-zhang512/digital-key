分析流程

从 PDF 到对比报告，两步完成

Phase 01
构建知识库

将芯片 PDF 规格书放入 spec/ 目录，运行切片脚本提取文本、分段、生成引用标签。

python build_reference.py
Phase 02
逐维度对比

读取 references/ 知识库，按通用维度＋技术专项维度检索原文，每条结论附 citation_tag。

chip-comparison-analysis
Output
双端输出

同时产出本地 Markdown 报告和飞书云文档，表格列宽通过 XML patch 精确控制。

lark-cli docs +create ...
